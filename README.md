# Applied-AI

Exercises and projects for the Applied AI course, covering Python, NumPy, 
Pandas, Matplotlib, Seaborn, Machine Learning, and Deep Learning.

# Tests

Only testing:
```bash
python3 -m unittest
```

Testing with coverage report:
```bash
coverage run -m unittest
```
then
```bash
coverage report -m
```
or as html
```bash
coverage html
```
